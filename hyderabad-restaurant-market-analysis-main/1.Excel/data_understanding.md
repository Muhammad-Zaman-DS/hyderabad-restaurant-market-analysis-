# Data Understanding

# Project Overview

This project analyzes restaurant data collected from Google Maps for restaurants located in Hyderabad, Sindh, Pakistan. The objective is to clean, organize, and analyze the data using SQL, Python, Microsoft Excel, and Power BI.

# Data Source

* Source: Google Maps
* Collection Method: Web Scraping
* Location: Hyderabad, Sindh, Pakistan
* Original Format: Microsoft Excel (.xlsx)

# Raw Dataset Overview

The raw dataset contained automatically generated column names, duplicate information, unnecessary metadata, image URLs, special symbols, missing values, and inconsistent formatting. These issues required data cleaning before analysis.

# Cleaned Dataset Structure

| Column          | Description                                   |
| --------------- | --------------------------------------------- |
| Restaurant_ID   | Unique identifier assigned to each restaurant |
| Google_Maps_URL | Google Maps link of the restaurant            |
| Restaurant_Name | Name of the restaurant                        |
| Rating          | Google Maps rating                            |
| Reviews         | Total number of customer reviews              |
| Price_Range     | Estimated price range                         |
| Category        | Restaurant category or cuisine                |
| Address         | Restaurant location                           |
| Status          | Current operating status                      |
| Opening_Hours   | Opening or closing hours                      |
| Customer_Review | Sample customer review                        |

# Dataset Purpose

The cleaned dataset is prepared for:

* SQL database creation
* SQL query analysis
* Python data analysis
* Microsoft Excel reporting
* Power BI dashboard development
* Portfolio project showcasing data analysis skills
