# SQL Analysis

## Overview

This document summarizes the SQL operations performed on the **Hyderabad Restaurant Analysis** dataset. The purpose of this analysis was to practice fundamental SQL concepts used in data analysis, including data retrieval, filtering, aggregation, grouping, and conditional logic.

---

## Database Setup

The project was created using **MySQL**.

### Database

* HyderabadRestaurantDB

### Table

* Restaurants

---

## SQL Concepts Applied

The following SQL concepts were used during this project:

* Database creation
* Database selection
* Table modification
* Data retrieval using `SELECT`
* Data filtering using `WHERE`
* Multiple conditions using `AND`
* Sorting results using `ORDER BY`
* Limiting records using `LIMIT`
* Removing duplicate values using `DISTINCT`
* Grouping records using `GROUP BY`
* Aggregate functions (`COUNT`, `AVG`)
* Filtering grouped data using `HAVING`
* Conditional categorization using `CASE`
* Handling missing values using `IS NULL`
* Filtering multiple values using `IN`

---

## Analysis Performed

The SQL queries answered several business-related questions, including:

* Display all restaurant records.
* Find restaurants with more than 1,000 reviews.
* Identify restaurants with ratings greater than or equal to 4.0.
* Sort restaurants by rating.
* Display a limited number of records.
* List unique restaurant names and operating status.
* Count restaurants by category.
* Calculate the average rating for each category.
* Filter categories with an average rating above 3.5.
* Classify restaurants based on rating using a CASE statement.
* Identify restaurants with missing price information.
* Filter restaurants belonging to selected categories.
